# potatis och pumpa soppa

## ingredienser

- pumpa
- potatis
- vitlök
- gul/röd-lök
- grädde
- buljontärningar

## processen

* skala och tärna pumpan
* skala, tärna och koka potatisen
* hacka och fräs lökarna
* blöt up buljontärningar i kokhet vatten
* fräs pumpabitarna tillsamman med löken
* häll på buljonen
* koka ca 5-10 min
* lägg i kokt potatis
* häll på grädden
* krydda
* purera soppan med mixerstaven
